FAR DIMSUM WEB/PWA

1. Install Python 3.
2. Buka Command Prompt di folder ini.
3. Jalankan:
   pip install -r requirements.txt
4. Jalankan:
   python app.py
5. Buka:
   http://127.0.0.1:5000
